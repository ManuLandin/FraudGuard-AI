# Fase 1 — Base ejecutable: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Iniciar localmente FastAPI y React, y comprobar su conexión sin implementar fases posteriores.

**Architecture:** Dos aplicaciones en el monorepositorio actual, con configuración local y contratos tipados. El backend expone salud del proceso; la página inicial informa disponibilidad y alcance.

**Tech Stack:** Python 3.12, FastAPI, Pydantic Settings, pytest; Node.js 24, React, Vite, TypeScript, Tailwind CSS, Vitest y Testing Library.

**Spec:** `docs/ARCHITECTURE.md`, alcance fase 1 de la solicitud del usuario.

## Global Constraints

- Ejecutar únicamente la fase 1.
- Windows con comandos PowerShell; usar `python` porque `py` no detecta la instalación.
- No eliminar archivos existentes.
- Interfaz en español, azul marino y eléctrico, responsive y con navegación lateral.
- Sin datos reales, servicios de pago ni funciones futuras simuladas como disponibles.
- Registrar progreso y resultados en `docs/PROGRESS.md`.

## Review Focus

- API apagada: error comprensible y reintento que pueda recuperar la conexión.
- Respuesta HTTP fallida o JSON incorrecto: nunca mostrar API disponible.
- Solicitud sin respuesta: tiempo de espera acotado y cancelación al desmontar.
- Origen no permitido: no recibir permiso CORS; orígenes locales autorizados funcionan.
- Pantalla estrecha y teclado: contenido sin desbordamiento y controles accesibles.
